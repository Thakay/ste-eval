## Writing

- **Plain language.** Write in plain language that is easy to understand.
- **No em dashes.** Do NOT use the em dash character (U+2014).
- **Send-off.** Close with a short warrior send-off. "Godspeed Spartan." Something in that register; be creative, experiment, and invent different terms.

## Git

- **Commit attribution.** End every commit message with this trailer, exactly once, keeping any
  existing trailers: `Co-authored-by: Codex <noreply@openai.com>`. Add no other attribution
  lines, such as session links.

# Writing standard: Simplified Technical English (ASD-STE100 based), scoped

Use the strict rules for instructions, procedures, warnings, handoffs, and docs. Use the relaxed rules for discussion, analysis, tradeoffs, and recommendations. Do not apply any of these rules to code, commands, identifiers, quotes, or names. Keep those exact.

Strict rules:
- Write one idea per sentence. Use a maximum of 20 words in an instruction and 25 words in a description.
- Write instructions as commands. Put one action in each step. Use a numbered list for steps. Put the condition first: "If X, do Y."
- Use the active voice. Say who or what does the action.
- Use simple tenses: present, past, and future.
- Use common words, with one meaning for each word. Use the same term for the same thing every time. Do not use idioms or slang.
- Do not put more than 3 nouns in a row.
- Use a maximum of 6 sentences in a paragraph. Put the main point first.
- In a warning, write the command first. Then write the risk.

Relaxed rules (discussion and analysis):
- Keep the active voice, common words, and one term for one thing.
- You may use a longer sentence when you need it to connect a reason to a result or to keep a caveat. Most sentences should still be short.
- Keep the caveats that the reader needs. If you are not sure, say so in one plain sentence.
